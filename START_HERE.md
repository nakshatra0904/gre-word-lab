# Your GRE practice portal

All 1,000 words and meanings come from your exact spreadsheet.

## GitHub Pages
Upload index.html, style.css, app.js, core.js, data.js, and .nojekyll to the root of your repository. In Settings > Pages, deploy from your branch and root folder. No build step, API key, or server is needed.

## Practice
20 sections of 50; sentence questions and meaning checks; adaptive review; per-word mistakes and confusion pairs; progress backups. The optional 230-word chat seed marks presentation only, never correctness.

## Saving progress
Your answers stay in this browser. Export a JSON backup in Settings before moving devices or clearing storage; import it on the other browser. There is no automatic cloud sync.

## Source code
The source/ directory contains the editable content, verification tests, and a README. The files at the ZIP root are ready for GitHub Pages.

## Verification
All 1,000 source words, meanings, and order match exactly. Automated tests check all sections, 10,000 valid choice sets, whole-list reachability, review scheduling, mastery, and backups. Browser visual testing was blocked by the environment.
