# Word Lab: Quiz 2 update

This package contains the complete updated website: your original Quiz 1 plus a separate Quiz 2 with 1,000 new GRE-style questions.

## Update your existing GitHub Pages site

1. Extract the ZIP.
2. Open your existing `nakshatra0904/gre-word-lab` repository on GitHub.
3. Choose **Add file → Upload files**.
4. Upload every extracted website file directly into the repository root, replacing files with the same names. Keep `index.html` and `quiz2.html` at the top level. Upload the extracted files, not the ZIP or an enclosing folder.
5. Commit the changes to `main`.
6. The existing GitHub Pages deployment will rebuild. Open your usual site link and choose **Quiz 2 · GRE formats**. If the link is not visible immediately, refresh after deployment completes.

Quiz 1 continues to use its original browser storage. Quiz 2 has separate progress and backups. Updating files at the same website address does not reset either quiz's progress. Export progress before clearing browser data or moving to another browser/device.

Quiz 2 → Guide & backup lists format/vocabulary sources and provides Quiz 2 export/import. Quiz 1 → Settings retains its original backup tools.

These are independently authored practice questions, not official ETS questions, a full GRE mock test, or a scaled-score predictor. Automated coverage, scoring, backup, and scheduling checks were run; visual browser verification was unavailable.
